# AI Network Lab: OSPF ECMP SONiC FRR

This repository contains an environment for emulating network topologies using Containerlab, specifically focusing on an OSPF-based Equal Cost Multi-Path (ECMP) routing setup in a pure SONiC/FRR environment.

## Project Structure

**Note:** The prompt and test files (`ospf-sonic-lab-prompt.md` and `ospf-sonic-lab-test.md`) are the most important files in this project.

- `ospf_sonic/`: Contains the main OSPF ECMP lab with SONiC.
  - `ospf-sonic-lab-prompt.md`: The lab topology design, IP addressing, and OSPF requirements.
  - `ospf-sonic-lab-test.md`: Essential verification guide and testing steps for the deployed lab.
  - `containerlab/`: The topology generated by the AI agent. This directory is kept here for reference and can also be used to directly start the SONiC OSPF topology.
- `agent_prompt.txt`: Initial instructions for generating the lab.

## Lab Topology

A diamond topology consisting of 4 routers and 2 hosts:

```text
                  R2 (SONiC/FRR)
                /                \
Host1 -- R1 (SONiC/FRR)        R4 (SONiC/FRR) -- Host2
                \                /
                  R3 (SONiC/FRR)
```

- **Routing:** OSPFv2 only, Area 0.0.0.0 backbone
- **Network Type:** Point-to-Point on all P2P links
- **ECMP Capability:** 2-path equal-cost load-balancing (R1↔R4 via R2 OR R3)

### IP Configuration

**Loopbacks (Router IDs):**
- R1: `1.1.1.1/32`
- R2: `2.2.2.2/32`
- R3: `3.3.3.3/32`
- R4: `4.4.4.4/32`

**Point-to-Point Links (/31):**
- R1 ↔ R2: `10.12.1.0/31`
- R1 ↔ R3: `10.13.1.0/31`
- R2 ↔ R4: `10.24.1.0/31`
- R3 ↔ R4: `10.34.1.0/31`

**Host Networks (/24):**
- Host1 ↔ R1: `192.168.1.0/24`
- Host2 ↔ R4: `192.168.2.0/24`

## Getting Started

### Prerequisites
- Docker
- [Containerlab](https://containerlab.dev/)

### Deployment
Navigate to the containerlab directory and deploy the topology (replace `<topology-file.yml>` with the actual topology file):

```bash
cd ospf_sonic/containerlab
sudo clab deploy -t <topology-file.yml>
```

## Testing & Verification

A comprehensive testing guide is provided in [`ospf_sonic/ospf-sonic-lab-test.md`](ospf_sonic/ospf-sonic-lab-test.md). The tests cover:

1. **Interfaces & MTU**: Validating that all OSPF links are functionally UP with correct MTUs (1500).
2. **OSPF Neighbor Convergence**: Ensuring all routers form `Full` adjacency.
3. **OSPF Database Synchronization**: Checking LSDB holds 4 Router LSAs per node.
4. **ECMP Route Verification**: Testing the routing tables to confirm multiple equal-cost next-hops are installed.
5. **Load Balancing & Convergence Test**: Using traceroute to test flow hashing and simulating link failures to ensure routing path redundancy.

To start verification, inspect the running lab:
```bash
sudo clab inspect -a
```
Then follow the commands outlined in the test document.
